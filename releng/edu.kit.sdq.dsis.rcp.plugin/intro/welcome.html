ArchSafe Unified Modeler

A model-driven workbench for co-designing system architecture and safety analysis of cyber-physical systems. ArchSafe semantically unifies SysML architecture concepts and RAAML safety-analysis concepts in a single EMF model, projecting multiple synchronized views that stay consistent by construction.

Modeling & Analysis Views

ARCHITECTURE

Architecture Diagram

System and safety-critical blocks with typed connections (DATA / CONTROL / SIGNAL / POWER / MECHANICAL) and structural associations.

SAFETY

Safety Diagram

Integrated hazards linked to the blocks they affect, with failure modes contained inside their safety-critical blocks.

REQUIREMENTS

Requirements Diagram

The ISO 26262 chain: Safety Goals → Functional → Technical Safety Requirements → Safety Mechanisms, traced to hazards and blocks.

FMEA

FMEA Diagram & Table

Failure Mode & Effects Analysis with automatic RPN (S×O×D), risk categorization, and one-click auto-generation from failure modes.

METRICS

Quality Metrics Dashboard

Live GQM scorecard (MCR, HTI, RAR, FLC, TDS, MVR) with PASS/GAP status against configurable thresholds.

SIMULATION

Failure Propagation Simulation

Interactive BFS what-if analysis: pick a failure source and watch effects propagate forward / backward across connections, revealing activated hazards.

TRACEABILITY

Automated Traceability Diagram

End-to-end, auto-generated trace network across hazards, requirements, architecture, FMEA, and mechanisms — no manual link maintenance.

Key Features

  • One unified metamodel (SysML ∪ RAAML) as a single source of truth.
  • Semantic validation rules aligned with ISO 26262 clauses.
  • Consistency by construction — architecture changes propagate to safety views.
  • Bidirectional, automated traceability via EMF references (eOpposites).
  • Interactive failure-propagation simulation built directly on the model.
  • Report export: Safety Case, FMEA, Traceability matrix, and Metrics (CSV/HTML).

Getting Started

  1. Use the bundled case studies in the install's casestudies/ folder (Automotive AEB and Medical Infusion Pump).
  2. File → Open Projects from File System… and select a case-study folder.
  3. Open its *.aird and pick a representation (Architecture, Safety, Requirements, FMEA, Metrics, Simulation, Traceability).
